# Fernhaus is Plant Store Website
This is a fictional plant shop and interior greening studio. 
The project was created for practice and is not a real business.

# About
Fernhaus is a fictional plant shop and interior greening studio for homes and offices. 
This is a practice project: a front-end store concept built from scratch with HTML, CSS and vanilla JavaScript, 
growing from a landing page into a small shop with a plant catalog, a shopping cart and a news section.

> Currently front-end only. A backend (API and database) is planned. Payments will be simulated.

# Roadmap
- Landing page with hero section
- Plant catalog (cards with photo, name, price)
- Shopping cart (add / remove items, total price)
- News section
- Contact / consultation form
- Mobile layout polish
- Backend API and database (planned)

# Built with
- HTML5
- CSS3 (Grid, Flexbox, gradients, masks)
- JavaScript
- GitHub Pages for hosting

# Status
In development. Planned next: product/service cards, gallery, contact section, mobile polish.
